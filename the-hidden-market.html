PROBLEM Job boards show you what's already been passed around internally for weeks.
SOLUTION Built an automated research workflow in Claude and Cowork that searches 20+ sources every morning, scores every role against a custom profile, and saves a ranked report before I finish my coffee.
OUTCOME Automated the research. Freed the time for actual applications.
WORKFLOW ·

Job boards are a lagging indicator. By the time a role hits Hitmarker it's already been shopped internally for weeks. I wanted a system that got ahead of that. Not a search. A workflow that runs without me.

Opened Claude Desktop. Switched to Cowork mode. Clicked New Task. Typed a prompt: research game UX jobs and save a report. It ran. Then it failed. No folder to save to.

That's the first thing Cowork taught me. Build the environment before you build the workflow. So I asked it to build the folder structure itself.

[ SCREENSHOT ] PROMPT drop image here · ~1600 × 900
The prompt that started it.

It created this:

/Users/jason/Desktop/JobHunt/
├── COWORK-INSTRUCTIONS.md
├── weekly-reports/
└── applied/

Cowork wrote the file, confirmed it was ready. Ran it. First report landed in 15 minutes. Scheduled it for 8am daily and didn't touch it again.

Since then I've tweaked the prompt a few times. Small adjustments. Tighter language around what I'm actually looking for. The results have gotten better with each iteration. More accurate. More tailored. The system gets better when the instructions get better. That's the job.

Seven roles. Nothing cleared 70%. A remote role at a casual mobile studio scored 45%. Wrong work. No progression systems, no live service, no IP. A hybrid role in Seattle at a AAA studio working on reward economies scored 68%. Close. Would have cleared if it were remote. The system wasn't filtering location. It was scoring the actual work against the actual job.

That's the value. A system that tells you the truth is more useful than one that makes you feel good.

Every morning the report is there. Open the folder. Read it. Apply to what matters.

One more layer. I run a parallel search in Gemini with Deep Research enabled using the same profile. Manual for now, but the logic is simple. If a role surfaces in both, it's a priority application. Two AIs finding the same role means it's real and it's a fit.
